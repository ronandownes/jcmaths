Functions sits within the combined Algebra and Functions strand. The learning outcome below is the H2 that feeds this dropdown.

AF.7 — Functions and their representations

Investigate functions; represent and interpret them graphically, diagrammatically, verbally and algebraically; use function notation; solve equations and inequalities graphically; and connect graph shape with phenomena.

A function such as \(f(x)=2x+1\) can be represented by a rule, a table of values and a graph. These are different views of the same relationship.
